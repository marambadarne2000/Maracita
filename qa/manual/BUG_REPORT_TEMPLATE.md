# Bug Report Template

| Field | Details |
| --- | --- |
| Bug ID | `MAR-###` |
| Title | Short, specific problem title |
| Reporter | _Name_ |
| Date | _YYYY-MM-DD_ |
| Environment | Browser, URL and build |
| Severity | Critical / High / Medium / Low |
| Priority | P1 / P2 / P3 |
| Preconditions | Required account or data |
| Steps to reproduce | Numbered steps |
| Actual result | What happened |
| Expected result | What should happen |
| Evidence | Screenshot, video or console detail |
| Status | New / In progress / Fixed / Retest / Closed |
